# ADR 015: Delegation binds session authority and takes explicit images

**Status:** Accepted · **Date:** 2026-10-28 · **Scope:** delegation follow-through for #35–#37

## Context

The native Claude and Codex clients accept images, but the delegation adapter exposed only a string prompt. Codex's generated catalog also declared every backend text-only, while the profiles and VS Code already declared qualified chat image input.

The adapter checked a resume UUID and prevented concurrent calls, but did not bind it to the agent, mode, directory or model that created it. Omitted options reused fresh-call defaults instead of the session's choices. Native clients allow overrides while resuming, so native session lookup does not enforce the adapter's stated same-agent/mode contract. Claude can also reuse its recorded system prompt across resumes until compaction.

## Decision

Keep native CLI inference and their transcript stores. Store only a private, versioned session binding under ailocal's disposable state root: UUID, CLI, worker root, mode, canonical requested/effective working directories, alias and execution-policy fingerprint. No prompt, reply, transcript or image bytes are retained there. Native session IDs remain public, but only IDs with a valid binding may resume through the tool. ID-only resumes inherit their choices; explicit conflicts and policy changes fail before launch. Every stronger mode rechecks the current operator ceiling. A different scope or mode starts a fresh delegation, with context explicitly supplied by the parent. Old unbound sessions are not silently adopted. Deleting disposable binding state makes those native sessions unmanaged by the tool; it does not delete native transcripts.

Image input is an optional list of explicit local paths, bounded to the supplied working directory even in text mode. Text workers still start in the owned empty directory and receive no additional tools. Read files through checked handles, deny credential-file identities and symlink escapes, cap size/count/dimensions, and stage immutable private copies. Use macOS's native `sips` metadata validation rather than adding a codec dependency. Limits are four PNG/JPEG images, 5 MiB each, 8192 pixels per side and 16 million pixels each. Native decode/model errors remain failures; metadata validation is not general image-quality certification.

Send one newline-terminated structured user message through an owned, asynchronously closed stdin pipe for Claude image calls; consume its terminal JSONL result with existing output bounds and process-group cleanup. Attach staged files with repeated Codex image flags, preserving fresh/resume parser differences. Never inherit the MCP protocol stdin. Exact-backend profile modalities drive Codex, VS Code and delegation eligibility. FIM is text-only. Parent attachments and tools are not copied implicitly.

Native completion without a final reply is still `DELEGATE_EMPTY`, not task success. Once the runner verifies completion and session identity, persist the same authority binding and include `resume=UUID` in that error. The caller may explicitly request a follow-up under the original choices; ceilings, scope and policy are checked again. No automatic retry, reasoning-to-answer promotion or mode change occurs. A binding-write failure advertises no resume handle. Fresh failed, cancelled and timed-out runs create no binding.

## Consequences

Resume cannot silently switch to Cyber/text or reuse a stronger session under a weaker mode. Policy changes require a fresh session. Native CLI transcripts remain client-owned. Binding metadata is authoritative only within the operator's local account; full mode already grants unsandboxed access and cannot be isolated from that account's files.

Attachments work without file-tool permission escalation, but callers must provide local paths and an explicit attachment scope. Remote URLs, automatic parent-conversation copying, video and PDF are outside this interface. Source/recipe fingerprints detect declared policy changes; they do not prove that an externally replaced mutable model tag still has identical weights.

## Alternatives

- A UUID plus prompt advice leaves scope changes unenforced and preserves the defaults bug.
- Reading private native transcript formats would couple ailocal to two client implementations and create a second history reader.
- Signed resume tokens would add a new key lifecycle and change the public resume handle without removing the need for concurrent-session locking.
- Changing modes on resume would require a separate tested transition contract, including old transcript content and recorded system instructions. Fresh delegation makes that change explicit.
- Image filenames embedded in prose require Read tools and do not guarantee binary image input. Base64 generated by the parent model inflates tool arguments. Native CLI attachments preserve the existing runtime path.
