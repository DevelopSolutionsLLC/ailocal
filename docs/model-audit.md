### Cause and fix — 2026-10-29 (#38, ADR 016)

The failing turns were not truncated reasoning: they held the final answer inside the open think block (the 9B's whole "thinking" was `DONE`, two tokens), the original real Codex turn included. Every earlier loop turn in the captured prompt was rendered as an empty `<think>\n\n</think>` block, the non-thinking signature, because Codex replayed no reasoning and Ollama's `Qwen35Renderer` writes a block for every post-query assistant turn. Gemma 4's renderer writes one only when reasoning exists.

## What counts as an enhancement

MTP uses a draft head whose proposals are checked by the target model; it can accelerate inference without additional training data. Calibration and mixed precision aim to preserve fidelity when compressing weights. QAT trains with quantization in mind. Coding SFT or distillation changes training exposure. Abliteration changes weights to reduce refusals; it does not by itself establish additional knowledge or preserved capability. MLX is an execution framework and format choice, not a training enhancement. Apply the [selection rule](maintenance.md#model-format) to each exact artifact.
